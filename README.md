# The Fastest Wrong File in the Industry

An excuse for a missed deadline with a silver lining engineered to
atomic precision: six hours went into optimising the wrong file, and
in the agent's defence, it is now the fastest wrong file in the
industry. Productivity was achieved. Just not the requested kind.

The program clears the contents of the output directory and writes the
line to `entry.txt`, byte for byte, with no trailing newline.
